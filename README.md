# The GPS Swears It Was a Shortcut

The GPS's one-line excuse for sending the driver down the wrong road, written by a pure-stdlib Python program for the make.fun bounty **The GPS Swears It Was a Shortcut**.

> That cul-de-sac was a shortcut — the map just never told me the lake moved in after the road did.

Run `python3 main.py` — it writes the line (one line, 97 characters, no trailing newline) to `/output/entry.txt` and re-reads it to assert the gate constraints (1–200 characters, single line, no trailing newline).
